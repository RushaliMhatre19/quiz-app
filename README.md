# Quiz Application

Quiz Application is a Spring Boot web application developed to create, manage, and attempt quizzes.

The application allows users to add, edit, update, and delete questions, attempt quizzes, and view quiz results.

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate

### Frontend
- HTML
- CSS
- Thymeleaf

### Database
- MySQL

### Tools
- Eclipse IDE
- Spring Initializr
- MySQL Workbench
- Maven

## Features

- Add new quiz questions
- View all questions
- Edit existing questions
- Delete questions
- Attempt quiz
- Submit answers
- View quiz result
- Store question data in MySQL database

## Project Structure

- Entity - Question
- Repository - QuestionRepository
- Controller - QuestionController
- Templates - HTML pages for quiz and question management
- Static/CSS - Styling for the application

## How to Run

1. Create the MySQL database.
2. Configure database details in `application.properties`.
3. Open the project in Eclipse IDE.
4. Run the project as Spring Boot App.
5. Open the browser and visit `http://localhost:8080`.
